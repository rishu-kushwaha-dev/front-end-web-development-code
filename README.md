# 🚀 Front-End Web Development Collection

Welcome to my official front-end development repository! This space is a collection of all the practical web applications, mini-games, UI components, and utility tools I have built using core web technologies. 

---

## 🌟 About This Repository
The goal of this repository is to showcase my front-end development skills, problem-solving abilities, and my journey of building real, functional web interfaces from scratch without relying on heavy frameworks.

---

## 📂 Project Structure & Features

Here is a breakdown of the projects included in this repository:


### 🛠️ Utility & Productivity Tools
* **Password Generator:** Generates secure and customizable random passwords instantly.
* **Colour Palette Generator:** A handy tool for designers and developers to create and copy color palettes.
* **Typing Speed Checker:** Tests user typing speed (WPM) and accuracy in real-time.
* **World Clock Dashboard:** Displays live time zones across the globe dynamically.

### 🌐 Web Applications & Layouts
* **Gift Bloom (Online Gift Store):** An e-commerce front-end layout featuring products and clean UI styling.
* **Shree Ice-Cream Parlour:** A responsive food/dessert menu and store layout.
* **Shree Palace Room Booking:** A hotel/room reservation interface concept.
* **To-Do List App:** A daily task manager allowing users to add, check off, and delete items.
* **Portfolios & Resumes:** Clean, responsive HTML/CSS templates.
* **Student Registration Form:** A form with input validation layouts.

## 🛠️ Tech Stack & Skills
All projects in this repository are crafted using:
* **HTML5:** Semantic and accessible document structure.
* **CSS3:** Modern styling, Flexbox, Grid, and responsive designs.
* **JavaScript (Vanilla JS - ES6+):** Dynamic event handling, DOM manipulation, and application logic.
